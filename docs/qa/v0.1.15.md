# v0.1.15 验证记录

日期：2026-10-16。

## 真实故障与原因

用户提供的真实 Markdown 文章包含六张 PNG 插图，正文同时讨论 `XABIMG1`、`XABIMG10` 两个占位标记示例。旧版生成的图片标记与正文示例重名。第二张图片上传后，位置检查继续命中正文示例；位置修复还可能把图片插入示例所在句子，损伤原文。

另外两项回归测试确认：位置更新提交后立即读取 DOM，会把延迟渲染误报为失败；已知媒体编号的图片在重试循环中仍会重新上传。

## 修复

- Markdown 和 HTML 均采用每次导入独立的标记命名空间，并检查命名空间不在源文中。
- 单张图片按服务器媒体编号等待编辑状态与 DOM 连续稳定，再继续处理下一张。
- 已上传图片重试时只确认和修复位置，初次位置回写失败也保留已知媒体编号。
- 分开显示上传数量与位置确认数量。
